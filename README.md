# 🧮 CalculusSolver

This repository contains a collection of small programs to solve various calculus problems using both **symbolic** and **numerical** methods.

---

## 📂 Files Overview

### Python Files
| File         | Description |
|--------------|-------------|
| `main.py`    | Entry point or general-purpose script (custom usage or testing). |
| `sym.py`     | Script containing the backend of main.py. Works using SymPy. |

### C++ Files
| File               | Description |
|--------------------|-------------|
| `2_diffbylim.cpp`  | Numerical differentiation. |
| `3_simpsons.cpp`   | Numerical integration using Simpson’s rule. |

---

## 📦 Requirements

Only needed for Python scripts:

- Python 3.7+
- `sympy`

Install with:

```bash
pip install sympy
